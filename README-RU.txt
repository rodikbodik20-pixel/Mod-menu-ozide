OXIDE MOD MENU — Android WebView project, version 0.1

Это автономное приложение-оболочка с локальным демонстрационным меню.
Оно НЕ подключается к Oxide, не внедряется в игру, не читает память и не обходит античит.
Переключатели являются визуальной демонстрацией для будущей собственной тестовой игры.

Сборка APK:
1. Откройте папку проекта в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Выберите Build > Build Bundle(s) / APK(s) > Build APK(s).
4. APK появится в app/build/outputs/apk/debug/app-debug.apk.

Требования: Android Studio с Android SDK Platform 35 и JDK 17.
